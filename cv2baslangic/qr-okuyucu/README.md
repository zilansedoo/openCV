# QR Code Reader 📷

Python ve OpenCV kullanılarak hazırlanmış basit bir QR kod okuyucudur.

## Kullanılan Teknolojiler

* Python
* OpenCV

## Özellikler

* Kameradan QR kod okuma
* QR kodun etrafına çerçeve çizme
* QR içeriğini ekranda gösterme
* `Q` tuşu ile çıkış

## Kurulum

```bash
pip install opencv-python
```
